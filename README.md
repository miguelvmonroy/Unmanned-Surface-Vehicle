## 📋 Project Description / Descripción del Proyecto

### 🇬🇧 English

This project involves the development of an **autonomous boat (USV)** capable of navigating independently using sensors, actuators, and advanced control systems. The vessel is designed to carry out monitoring, exploration, and data collection missions in aquatic environments.

#### 🎯 Main Objectives

- Autonomous navigation without human intervention
- Real-time obstacle avoidance
- Environmental monitoring and data collection
- Real-time communication with the base station

### 🇪🇸 Español

Este proyecto consiste en el desarrollo de una **embarcación autónoma (USV)** capaz de navegar de forma independiente utilizando sensores, actuadores y sistemas de control avanzados. La embarcación está diseñada para llevar a cabo misiones de monitoreo, exploración y recolección de datos en entornos acuáticos.

#### 🎯 Objetivos Principales

- Navegación autónoma sin intervención humana
- Evasión de obstáculos en tiempo real
- Monitoreo ambiental y recolección de datos
- Comunicación en tiempo real con la estación base

## 🛠️ Technologies Used / Tecnologías Utilizadas

### 🇬🇧 English

#### Hardware

- **Microcontroller**: ESP32 / Arduino Mega
- **Sensors**:
  - GPS (NEO-6M)
  - IMU (MPU6050)
  - Ultrasonic (HC-SR04)
- **Actuators**:
  - Electric motor with ESC controller
  - Servo motors for rudder
- **Battery**: 12V 20Ah Lithium

#### Software

- **Language**: C++ / Python
- **Framework**: ROS 2 (Robot Operating System)
- **Simulation**: Gazebo Harmonic with VRX
- **Control**: PID for stabilization and navigation
- **Interface**: Tkinter / Web Dashboard

### 🇪🇸 Español

#### Hardware

- **Microcontrolador**: ESP32 / Arduino Mega
- **Sensores**:
  - GPS (NEO-6M)
  - IMU (MPU6050)
  - Ultrasónico (HC-SR04)
- **Actuadores**:
  - Motor eléctrico con controlador ESC
  - Servomotores para el timón
- **Batería**: Litio 12V 20Ah

#### Software

- **Lenguaje**: C++ / Python
- **Framework**: ROS 2 (Robot Operating System)
- **Simulación**: Gazebo Harmonic con VRX
- **Control**: PID para estabilización y navegación
- **Interfaz**: Tkinter / Panel Web

## 🚀 Key Features / Características Principales

### 🇬🇧 English

#### Operation Modes

- **Manual**: Remote control from base station
- **Semi-autonomous**: Navigation assistance
- **Autonomous**: Fully independent navigation

#### Features

- ✅ Waypoint-based route planning
- ✅ Dynamic obstacle avoidance
- ✅ Navigation data logging
- ✅ Real-time telemetry transmission
- ✅ Safety system with automatic emergency response

### 🇪🇸 Español

#### Modos de Operación

- **Manual**: Control remoto desde la estación base
- **Semi-autónomo**: Asistencia a la navegación
- **Autónomo**: Navegación totalmente independiente

#### Características

- ✅ Planificación de rutas basada en waypoints
- ✅ Evasión dinámica de obstáculos
- ✅ Registro de datos de navegación
- ✅ Transmisión de telemetría en tiempo real
- ✅ Sistema de seguridad con respuesta de emergencia automática
